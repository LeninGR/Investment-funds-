## How to run locally

### Prerequisites
- Java 25 (OpenJDK 25)
- Gradle 9.x or later (or use the provided wrapper)

### Build and Run
```bash
# Using the wrapper (Recommended)
./gradlew clean build
./gradlew bootRun
```

The application will be available at http://localhost:8080/hello
